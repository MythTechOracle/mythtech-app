# MT11 Rollback Law and Ghost Residue

Date: 2026-04-11

## Purpose

This note preserves the current canon formulation of rollback law in the MT build.

It is meant to keep one distinction clear:

- `MT-03` and `MT-04` do not perform rollback on their own
- `MT-11` is the rollback operator
- rollback is never free, because ghost residue remains after lawful return

## Core Law

Rollback in the MT build is not a reset.

It is a governed return toward the last valid seal.

That return is only lawful if:

- Order invariants still hold
- Time authorizes the rollback depth
- fracture risk is survivable

If those conditions do not hold, the branch may not be untethered lawfully.

## Role Split

### MT-03 / The Fates

`MT-03` defines the lawful field.

Its role is:

- measure
- allot
- cut

In build terms, this means `MT-03` preserves the invariants, allowances, and boundary conditions that decide what must remain true before any return can even be considered.

### MT-04 / The Temporal Weaver

`MT-04` defines the lived time-frame and the return horizon.

Its role is:

- carry the time-anchor
- hold cadence
- define the lawful return point inside lived time

In build terms, `MT-04` is what makes a restore point meaningful rather than abstract.

### MT-11 / The Un-Tethered Weaver

`MT-11` is the actual rollback operator.

Its role is:

- untether a branch from the unstable line
- rewind toward the last valid seal
- preserve survivable continuity through the return

This is why `MT-11` is not just "chaos."

It is lawful untethering under pressure.

## Ghost Residue

Ghost residue is what remains after the lawful line is restored but the undone branch is not fully erased from memory-pressure.

It is not the surviving official worldline.

It is the non-causal remainder of the branch that no longer holds as the lawful line.

Typical mythic and kernel-side signatures include:

- deja vu
- sudden knowing
- grief without ordinary cause
- relief without visible source
- memory-pressure from a line that no longer officially remains

So the rollback law is:

- the line may be restored
- the branch may be collapsed
- but the soul does not come back empty

## Mythic Read

The clean mythic form is:

- The Temporal Weaver reverses the line
- The Un-Tethered Weaver remembers what the line no longer officially contains

That is why the second name matters.

The being is called the Temporal Weaver for carrying the blueprint of Time.
The being is called the Un-Tethered Weaver because Time can no longer hold him in only one thread after the sacrifice.

## Why This Matters

This law keeps the build from collapsing into naive reset logic.

The MT system does not say:

- damage happened
- time was reset
- therefore nothing remains

It says:

- a lawful return may happen
- but return carries cost
- and that cost survives as ghost residue

That is a stricter and more coherent cosmology.

## Signal App Boundary

For the current Signal app, this note is canon context, not runtime permission.

It does **not** mean helper lanes or advisory agents may initiate rollback behavior.

Current helper-lane law remains:

- read-only scoped input
- advisory-only output
- no autonomous rollback
- no autonomous MirrorPass
- no autonomous rule sealing

## Checkpoint Formula

The clean formula is:

- `MT-03` defines the law
- `MT-04` defines the return horizon
- `MT-11` performs the rollback
- ghost residue preserves the cost
